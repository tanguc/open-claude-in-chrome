OCIC Benchmark · Dataset Spec · v4.1 (dashdish × zilloft)

REAL tasks · dashdish × zilloft

The task set for the Open Claude in Chrome vs Claude in Chrome study, feeding the pre-training (experiential vs expert) and execute_code experiments. Built from the REAL suite, omnizon excluded (DMCA). v4 replaces fly-unified with dashdish (fly's host intermittently trips a Brave security interstitial); both apps carry hard tasks and every hard task sits in the test set.

18 tasks (3 easy · 11 med · 4 hard) dashdish 2e+5m+2h · zilloft 1e+6m+2h 6 train (3+3, all medium) 12 test (incl. all 4 hard) seeds 716 + 717 (zilloft pinned from v3) test ×1 (single rep) model sonnet · medium thinking

v4.1 design (seeds 716 + 717): train is deliberately all-medium, 3 per app; every hard task (dashdish-7, dashdish-10, zilloft-9, zilloft-10) is held out for test. dashdish uses its exact medium supply (all 5: 3 to train, 2 in test) with 2 of 3 easies and 2 of 3 hards drawn; zilloft's selection is pinned unchanged from v3. v4.1 promoted dashdish-5 from test to train (seed 717) to correct the split to 3 train mediums per app. fly-unified dropped (intermittent Brave "Security error" interstitial); networkin dropped earlier (zero hard tasks).

Design (seeds 716 + 717): dashdish = all 5 mediums + 2 of 3 easies + 2 of 3 hards, 3 mediums → train (dashdish-5 promoted from test in v4.1); zilloft pinned from v3 (1e + 6m + 2h, 3 mediums → train). Every hard task is in test. fly-unified dropped (intermittent Brave interstitial); networkin dropped (zero hard).
Grading: state-checked = all evals jmespath against /finish differences; LLM-judged = at least one llm_boolean rubric (judge runs via claude sonnet here; REAL default is gpt-4o).
Tracked decision: single rep per test task due to compute limits; per-task deltas carry unaveraged variance. Model everywhere: sonnet, medium thinking. Freshness per rollout: clear → /config → assert empty → run.
