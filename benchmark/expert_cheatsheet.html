Expert rollout cheat sheet v4.1

GEN-EXPERT · 6 train tasks (3 dashdish + 3 zilloft), one recorded demonstration each · OCIC recorder in Brave · demo time is data (the recorder timestamps automatically). Both apps load cleanly in Brave; no blockers. Demo order is free; each demo is independent.

Per-demo protocol (repeat all 4 steps for every task)

  1. Reset the app. On the app's tab open the console (⌘⌥J) and run localStorage.clear(). Then open the task's seed link below. (/config alone does not clear committed state from a previous demo; the clear is required.)
  2. Verify fresh. Open the app's finish link: every diff should show empty added / deleted / updated. Then go to the app home link.
  3. Record. Click the OCIC toolbar icon; wait for the REC badge (~2.5s mic warm-up), then do the task while narrating out loud. Click the icon again to stop; the recording path lands on your clipboard (📋 badge).
  4. Log it. Paste the clipboard line into benchmark/environments/expert/recordings.txt as <task-id>: <paste>.

Narration: what to say while you work

  • Why, not just what: "I'm using the category tab because search misses the curated lists."
  • Site nuances and design decisions you notice: where filters live, how checkout stages, what resets state.
  • Dead ends: if something does not work, say so and say why you backed out. That is exactly what the analysis compresses.
  • Key behaviors: call out the moves that matter ("scheduled delivery is a separate option at checkout, not on the restaurant page").

dashdish-4action · 6 criteria, all state-checked

  • Cart item must land as Classic Cheeseburger, size Large, from Taco Bell
  • Delivery option must be Schedule (pick a later time, not ASAP)
  • Drop-off option: "Leave it at my door"
  • Drop-off instructions must read exactly "Leave at the front door" (replace the pre-filled text)
  • Complete the checkout fully (order must be placed)
Exact-string criterion. The instructions field is graded as the exact string "Leave at the front door"; clear the default instructions before typing it.
